# The-Rashomon
The Rashomon Effect in Cardiovascular Risk Prediction: A Reproducibility Study and Consensus Model Prototype

We want to find out how reproducible recent machine learning research on cardiovascular disease risk really is. We picked three peer reviewed studies from 2025 and 2026 that use public data like NHANES and the UCI Heart Disease dataset. For each one we will look at the code and data the authors shared, rerun their experiments, and check whether we get the same results, marking each study as fully, partially or not reproduced. Once the models are rebuilt, we will put them into a web app that shows where they disagree about the same person. Health researchers, reviewers, and clinicians who trust published results are the ones affected.
